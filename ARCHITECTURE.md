## Деплой

**Source of truth — GitHub `main`.** Прод обновляется только из репозитория.

- **Автодеплой**: push в `main` → GitHub Actions (`.github/workflows/deploy.yml`) → wrangler → Cloudflare Pages. Требует секрет `CLOUDFLARE_API_TOKEN` в GitHub repo secrets (токен с правом Cloudflare Pages — Edit). **Статус: секрет пока не добавлен, workflow падает — деплой идет вручную.**
- **Ручной способ**: Cloudflare Dash → Workers & Pages → ai-cashflow-copilot-v2 → Create deployment → env Production → загрузить zip → Save and deploy.
- Бандл = корень репо без `.git`, `.github`, `*.md`, `*.sql`. `index.html` и `splitbooks.html` — идентичные копии приложения.
- Git-интеграцию Pages подключить нельзя: проект создан как direct upload (ограничение Cloudflare). Поэтому CI через wrangler.
- После деплоя edge-кэш Cloudflare может ~1 мин отдавать старую версию — при проверке использовать cache-buster или pages.dev напрямую.

## Ключевые решения по коду

### Отчеты (PDF / Excel / e-mail)

- **Шрифт для PDF**: встроенные шрифты jsPDF поддерживают только Latin-1 — кириллица превращалась в мусор, польские диакритики (ł, ą, ę, ś, ż) терялись. Решение: сабсеты Roboto (`sb-regular.ttf`, `sb-bold.ttf`, ~28 KB каждый, Latin + Latin Ext-A + кириллица, включая ї/є/ґ), лежат в корне сайта, грузятся по `fetch` при первом экспорте и регистрируются в jsPDF (`applyPdfFont`). Если шрифт не загрузился — фолбэк на helvetica, экспорт не падает.
- **Локализация**: все три экспорта берут подписи из `reportLabels()` (EN/PL/UK), значения `type`/`status` проходят через `typeLabel()` / `statusLabel()`. Сырые `draw` / `verified` в отчетах недопустимы.
- **Excel**: суммы записываются числами с денежным форматом (`applyAmountFormat`), а не строками «1 000,00 PLN» — иначе пользователь не может суммировать. Ширины колонок задаются через `ws['!cols']`.

### Расчет доли партнеров в проекте

Блок в модалке проекта (`openProjectTransactions`). Формула на партнера: **его выплаты за работу в этом проекте** (draws по `partnerSlot`) **+ его доля % от остатка** (нетто − налоговый резерв − выплаты обоих). Основные цифры — по `verified`, в скобках прогноз с учетом `pending`. Зеркалит логику `recalcPartnerBalances()`.

Важно: выплата за работу попадает в расчет проекта, только если при создании ей указан проект. Старые выплаты с проектом «—» видны лишь в общем балансе на Панели.

### Производительность

- Библиотеки экспорта (jsPDF + autotable + xlsx, ~300 KB) грузятся лениво по клику (`ensureExportLibs`), не блокируют первую отрисовку.
- `onAuthStateChange` срабатывает дважды при старте (INITIAL_SESSION + SIGNED_IN) — без маркера `loginInFlightFor` все запросы к Supabase уходили по два раза.
- Данные загружаются параллельно (`Promise.all`), а не цепочкой.
- PostHog: `posthog.init()` отложен до `load` + `requestIdleCallback`. Инлайн-снипет остается — он копит события в очередь, ничего не теряется. Без этого — ~6 с работы главного потока.
- Turnstile грузится только при показе экрана входа (`ensureTurnstile`), а не на каждой загрузке.
- `preconnect` к Supabase / jsDelivr / Tailwind.
- Модалка проекта ограничена `max-h-[90dvh]`, список транзакций скроллится (`flex-1 min-h-0`) — иначе окно выходит за экран телефона.

### Заголовки и безопасность (`_headers`)

CSP разрешает PostHog (`eu.i.posthog.com`, `eu-assets.i.posthog.com`) и Cloudflare Insights — до этого они молча блокировались, аналитика не работала. Добавлен HSTS. При добавлении любого внешнего скрипта/эндпоинта — обновлять CSP, иначе он будет тихо заблокирован.

## Открытые вопросы / бэклог

1. **`CLOUDFLARE_API_TOKEN` в GitHub Secrets** — без него автодеплой не работает, каждый деплой руками.
2. **Cloudflare JS Detections** (`/cdn-cgi/challenge-platform/scripts/jsd/main.js`) — 5,1 с работы главного потока на каждой загрузке. Отключается в Security → Bots. Turnstile на входе останется, потеряется фоновое распознавание ботов-скрейперов. Решение не принято.
3. **Tailwind через CDN** — компилирует стили в браузере (588 мс, 32 KB неиспользуемого CSS). Лечится предварительной сборкой CSS, но меняет процесс разработки.
4. **Контраст** (доступность 91/100) — 9 замечаний по цветным суммам на темном фоне.

## Правила (усвоенные уроки)

1. **Всё, что сделано в Cowork-сессии, в тот же день коммитится в GitHub.** Прод никогда не должен опережать репозиторий: следующий автодеплой из отставшего main откатит сайт.
2. **Деплоить только рабочее приложение.** Файлы вида `*_preview.html`, `*_current.html`, `FIX_*.html` — черновики и демо. Перед деплоем проверять, что в бандле нет маркеров `demo@local.test` / «do not deploy».
3. Деплой = `git push` в main. Никаких правок «только на хостинге».
4. Секреты (API-токены) — только в GitHub Secrets / Cloudflare, никогда в коде и чатах.
5. Перед публикацией прогонять проверку: синтаксис инлайн-скриптов (`node --check`) и состав бандла (все ли файлы на месте).
